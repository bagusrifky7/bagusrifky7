# Hi there, I'm Bagus Rifky Riyanto

## About Me
I'm a **Software Engineer and DevSecOps** who designs systems end to end: from service boundaries and data models to APIs, frontends, and the pipelines that ship them. I build backend services in Python and TypeScript, orchestrate AI agent workflows, and own the infrastructure (DevSecOps) that keeps everything reliable, observable, and scalable.

## What I'm into
- **System Design** – Architecting scalable, fault-tolerant systems: service boundaries, data flow, caching, queues, consistency, and trade-offs that hold up under real load.
- **Backend Engineering** – Designing and building robust APIs and services with FastAPI, Quart, and **NestJS**: microservices, event-driven architectures, clean modular design.
- **Full-Stack Development** – Shipping production UIs with **Next.js** and React (TypeScript, TanStack Query, Tailwind CSS), wired cleanly to the services behind them.
- **AI Agents & Orchestration** – Building and deploying RAG pipelines and intelligent agents that streamline real workflows.
- **DevOps & Infrastructure** – Containerization, CI/CD pipelines, and infrastructure automation across on-prem and cloud environments.
- **Observability & Reliability** – Logging, tracing, and metrics so problems get caught before they become incidents.
- **Pipeline Orchestration** – Automating ETL/ELT workflows for scalable, maintainable data systems.
- **Cloud & MLOps** – GCP and AWS for ML model hosting, lifecycle management, and Kubernetes-based deployment.
